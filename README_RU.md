# Forest Survival 3D — Android / Godot 4

Это стартовый игровой проект на Godot 4 для 3D-выживания от третьего лица. Лес, деревья, камни, ягоды и животные создаются процедурно, поэтому внешние модели не требуются.

## Уже есть в прототипе
- 3D-лес с процедурно расставленными деревьями, камнями, кустами и животными.
- Персонаж от третьего лица.
- Здоровье, голод, жажда и выносливость.
- Сбор древесины, камня и ягод.
- Простая охота/атака, мясо.
- Крафт каменного топора и лука (дальний бой пока заготовка).
- Строительство простого укрытия.
- Локальное сохранение состояния в `user://forest_survival_save.json`.
- Кнопки действий на экране.

## Важно
Это **играбельный прототип/основа**, а не законченная коммерческая игра. В текущей версии управление движением в основном рассчитано на клавиатуру; для полноценного мобильного управления нужно добавить виртуальный джойстик и свайп-управление камерой. Анимации, полноценная система стрельбы из лука, питьё из водоёмов, полноценная постройка стен/дверей, меню паузы и тестирование APK — следующие этапы.

## Как запустить на ПК
1. Установи Godot Engine 4.x (лучше актуальную стабильную версию 4.x).
2. Запусти Godot Project Manager → Import.
3. Выбери `project.godot` из этой папки.
4. Открой проект и нажми F6/F6 или F5 для запуска главной сцены.

## Как собрать APK для Android
1. Установи Godot 4.x.
2. Установи Android Studio и Android SDK, включая Android SDK Platform-Tools, Build-Tools и Android Platform.
3. В Godot открой **Editor → Editor Settings → Export → Android** и укажи пути к Android SDK и Java SDK/JDK (для версии Godot используй совместимую JDK, обычно JDK 17 для актуальных Godot 4.x; сверяйся с официальной документацией конкретной версии).
4. В Godot: **Project → Export** → Add… → Android.
5. Для тестового APK включи debug export. Если шаблоны экспорта не установлены, Godot предложит скачать Export Templates для той же версии редактора.
6. Укажи имя пакета, например `com.example.forestsurvival3d`.
7. Нажми **Export Project**, сохрани как `ForestSurvival-debug.apk`.
8. Перед установкой разреши установку приложений из выбранного источника Android, затем открой APK на телефоне.

Официальная документация: https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html

## Рекомендации для Vivo V40 (Snapdragon 7 Gen 3)
- Используется Mobile-friendly **Compatibility / OpenGL** renderer.
- Начни с разрешения 1280×720; на телефоне при необходимости снизь render scale/3D scaling.
- Для дальнейшего улучшения FPS: объединить повторяющиеся деревья через MultiMeshInstance3D, уменьшить количество теней, добавить дистанцию прорисовки/LOD и не обновлять каждый объект каждый кадр.
- Не рассчитывай на фиксированные 60/120 FPS до профилирования на устройстве.

## Управление в текущей версии
- WASD / стрелки — движение.
- Shift — бег.
- E — собрать ближайший ресурс.
- ЛКМ — атаковать ближайшее животное.
- Кнопки справа — крафт, строительство, еда, сохранение.
- Камера: удерживай правую кнопку мыши и двигай мышь в редакторе/на ПК.
